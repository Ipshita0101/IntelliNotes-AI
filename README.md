# 🧠 IntelliNotes AI

AI-Powered Smart Notes & Exam Preparation Assistant built using Streamlit, Groq LLM, OCR, and PDF/Image Processing.

---

## 🚀 Features

- 📄 Upload PDF Notes
- 🖼 Upload Images (PNG, JPG, JPEG)
- 🤖 AI Generated Summaries
- 🧠 Smart Exam Revision Notes
- 🔍 OCR Text Extraction
- 📚 Quiz Generation
- 🌙 Modern Dark Technical UI
- ⚡ Fast AI Responses using Groq API

---

## 🛠 Tech Stack

- Python
- Streamlit
- Groq API
- OCR.Space API
- PyPDF2
- HTML/CSS
- dotenv

---

## 📂 Supported Files

- PDF
- PNG
- JPG
- JPEG

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Ipshita0101/IntelliNotes-AI.git
cd IntelliNotes-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## 🔑 Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_groq_api_key
OCR_API_KEY=your_ocr_api_key
```

---

## ▶️ Run Locally

```bash
streamlit run app.py
```
